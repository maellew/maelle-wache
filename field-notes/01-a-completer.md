# [Titre : le moment où j'ai changé d'avis sur quelque chose]

Le format qui marche le mieux ici, d'après le plan initial : une erreur de raisonnement qu'on a corrigée. Pas besoin de données client, zéro risque de confidentialité — le sujet, c'est le jugement, pas les données de quelqu'un d'autre.

Trois questions pour la structurer :

- Qu'est-ce que je pensais au départ, et pourquoi ça semblait évident sur le moment ?
- Qu'est-ce qui m'a fait changer d'avis ?
- Qu'est-ce que je ferais différemment aujourd'hui ?
